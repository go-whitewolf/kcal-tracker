# Калориен баланс

Личен дневник за калориен баланс. Снимаш храната, Claude оценява калориите, записът влиза
в дневника. Следи тегло, тренировки и — най-важното — сверява изчисления разход с реалния,
изведен от промяната на теглото.

Статичен сайт без build step. Няма npm, няма bundler, няма зависимости.

---

## 1. Отваряне във VS Code

```bash
cd kcal-tracker
code .
```

`CLAUDE.md` в корена държи целия контекст за проекта. Claude Code го чете автоматично при
стартиране — не е нужно да обясняваш архитектурата всеки път.

Ако още нямаш разширението:

```bash
npm install -g @anthropic-ai/claude-code
```

После в VS Code инсталирай разширението Claude Code от Marketplace и се логни с Max
акаунта си. В терминала на VS Code `claude` стартира сесия в текущата папка.

## 2. Локално пускане

ES модулите не работят през `file://` — трябва HTTP сървър:

```bash
python3 -m http.server 8080
```

Отваряш `http://localhost:8080`.

## 3. API ключ за оценката по снимка

Вземи ключ от [console.anthropic.com](https://console.anthropic.com) → API Keys.

В приложението: **Профил → Оценка по снимка → Anthropic API ключ**. Натисни
„Провери връзката“, за да потвърдиш, че работи.

Ключът стои в storage на устройството и не влиза никъде в кода или в git.

**Кой модел.** В „Профил → Оценка по снимка“ избираш между четири:

| Модел | 100 оценки | Кога |
|---|---|---|
| Haiku 4.5 | под $0,50 | прости, ясни чинии |
| **Sonnet 5** | около $1 | по подразбиране — стига за почти всичко |
| Opus 5 | около $4 | смесени чинии, ресторантски порции, скрито олио |
| Fable 5.1 | около $8 | най-способният; има смисъл само при трудни снимки |

При четири снимки дневно Sonnet 5 излиза около долар на месец. Започни с него и мини
нагоре само ако забележиш, че бърка систематично в една посока.

### Ако не искаш ключът да е в браузъра

Папката `worker/` съдържа Cloudflare Worker, който държи ключа от страна на сървъра:

```bash
npm install -g wrangler
cd worker
wrangler login
wrangler secret put ANTHROPIC_API_KEY
wrangler deploy
```

Отвори `worker/index.js` и добави адреса на сайта си в `ALLOWED_ORIGINS`. После в
приложението избери „през собствен прокси адрес“ и сложи адреса на worker-a.

Безплатният план на Cloudflare дава 100 000 заявки дневно — многократно повече от нужното.

## 4. На телефона

Приложението е публикувано и работи на:

**https://go-whitewolf.github.io/kcal-tracker/**

Отваряш адреса на телефона → менюто на браузъра → „Добави към началния екран“. Появява се
с икона, отваря се на цял екран и работи офлайн. HTTPS идва наготово от GitHub Pages, така
че камерата работи.

Всяка промяна се публикува с три команди — сайтът се обновява за около минута:

```bash
git add .
git commit -m "какво е променено"
git push
```

> Репото е публично, но данните и ключът остават на телефона ти — в кода няма нищо лично.
> Всеки друг, който отвори адреса, вижда празен дневник и трябва да въведе свой ключ.

**Ако го даваш на колега:** пращаш му само адреса. Той минава през първоначалния екран със
своите мерки и си вади собствен ключ от console.anthropic.com — плаща своите снимки, вижда
своите данни. Нищо не се споделя между вас. Единственото, което не работи, е синхронизация
между неговите собствени устройства: телефон и лаптоп са два отделни дневника.

## 5. Как се ползва

**Първото пускане.** При първо отваряне приложението иска тегло, ръст, възраст, пол,
колко подвижен е денят извън тренировките и какъв темп на отслабване искаш. Попълва се
веднъж; после всичко се променя от „Профил“ по всяко време. Ако даваш адреса на друг човек,
той минава през същия екран на своя телефон и получава свой, празен дневник — вижда само
това, което сам е въвел.

**Снимката.** Бутонът „Снимай храната“ отваря камерата директно. След снимката можеш да
добавиш подсказка — „хотелски бюфет“, „пилешкото е с кожа“, „сосът е на маслена основа“.
Оценката се подобрява осезаемо, защото окото на модела не вижда как е готвено.

Резултатът идва разбит по компоненти, всеки с редактируемо поле за калориите. Нищо не влиза
в дневника, преди да го потвърдиш.

**Тренировките.** Избираш вид и минути; калориите се смятат от теглото ти по MET таблица.
При бягане въведи километрите вместо минутите — по-точно е (около 0,95 kcal на килограм
тегло за километър, почти независимо от темпото).

**Тегленето.** Сутрин, на гладно, преди вода. Дневните колебания са вода и съдържимо на
червата, не мазнина — гледай кривата, не отделния ден.

**Сверката.** След седмица с попълнени хранения и две измервания приложението изчислява
реалния ти разход от простото уравнение: приети калории минус промяна на запасите. Ако
излиза с повече от 150 kcal разлика от изчисления, коригирай целта. Оттам нататък работиш
с твоите числа, а не с формула.

## 6. Архив

**Профил → Свали архив** дава JSON с всичко. Данните живеят в браузъра и се губят при
изчистване на кеша или смяна на телефон, така че сваляй архив от време на време.
„Възстанови“ го връща обратно.

## Структура

```
index.html              трите изгледа
css/app.css             стилове, токени в :root
js/util.js              дати, форматиране, DOM хелпъри
js/storage.js           единствената точка за достъп до диска
js/state.js             обектът S — източник на истина
js/energy.js            BMR, MET, баланс
js/vision.js            камера + Claude API
js/views/               по един файл на изглед
worker/                 Cloudflare прокси (по избор)
CLAUDE.md               контекст за Claude Code
```
